# PrepMap

PrepMap helps students decide what to study first for university exams, using the
questions that have already appeared in past papers.

## Problem

Students prepare from scattered notes, photocopied papers and WhatsApp PDFs.
Two questions stay unanswered:

- Which topics carry the most marks across the years?
- Where are all the questions on one topic, in one place?

The result is wasted study time and last-night panic.

## Users

Students preparing for university exams. First testers: my classmates.

## Features

1. Create a subject and its topics (the syllabus units)
2. Add past-paper questions: short title, year, marks, topic
3. Edit and delete questions
4. Search and filter by subject, topic, year and text
5. Topic frequency chart (how many questions per topic)
6. Topic priority view: topics ranked by marks, with a cumulative percentage
7. Mark topics as revised and see progress
8. Export and import data as JSON
9. Shared data through a server and database (later version)
10. Moderation of new questions (later version)

## Data and copyright

The app does not store full question papers. It stores a short paraphrased title,
the year, the marks and the topic. The focus is on patterns, not on copying papers.
